# Release policy

## Public research edition

Publish documentation, a sample CSV, the data dictionary, transparent descriptive indicators, and selected reproducible tables. This layer demonstrates the method and supports external scrutiny.

## Licensed / commissioned edition

Retain model probabilities, detailed constraint diagnostics, firm-capability matches, scenario outputs and sector-specific treated datasets for licensed or commissioned work.

## GitHub

Use GitHub Pages for documentation and research presentation, not payment processing. Large release files should be attached to GitHub Releases rather than committed to the repository. Keep ordinary repository files below GitHub's large-file thresholds.
