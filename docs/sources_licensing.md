# Sources and licensing

## CEPII BACI

BACI 202601 is the initial trade backbone. CEPII lists the database under the Etalab 2.0 licence and provides HS6 bilateral values and quantities through 2024. Cite CEPII and Gaulier & Zignago (2010) in derived research.

## Redistribution policy

The public release should contain only fields and transformed data whose redistribution is permitted under upstream terms. Do not embed proprietary records from commercial shipment providers into public files unless the licence explicitly allows redistribution.

## Commercial layer

The internal database may combine public-source derived variables with client-supplied information. Client-confidential data must remain segregated and should never be used to enrich a public release without explicit permission.
